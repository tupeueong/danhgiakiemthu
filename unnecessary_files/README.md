# THƯ MỤC CÁC TỆP TIN TẠM THỜI & BẢN NHÁP (UNNECESSARY / SCRATCH FILES)

Thư mục này được tạo nhằm gom toàn bộ các tệp tin trung gian, bản nháp trích xuất dữ liệu và script phân tích phát sinh trong quá trình chuẩn bị kế hoạch kiểm thử:

1. **Các file trích xuất văn bản nháp:**
   - `nhom_5_extracted.txt`, `nhom_5_summary.txt`, `nhom_5_tasks.txt`: Bản bóc tách nội dung thô từ file Word Nhóm 5.
   - `nhom_5_ch1_ch2.txt`, `nhom_5_ch3_ch4_sample.txt`, `nhom_5_ch5_6_7.txt`: Các phân đoạn tham chiếu cấu trúc của Nhóm 5.
   - `nhom_9_extracted.txt`, `doc9_content.txt`: Khung outline ban đầu của Nhóm 9.

2. **Các script phân tích trung gian:**
   - `analyze_docx.py`, `analyze_fe.py`, `inspect_docs.py`, `summarize_nhom5.py`: Script Python dùng để đọc cấu trúc Word và mã nguồn Frontend.

Toàn bộ các file này được lưu giữ tại đây để không làm xáo trộn cấu trúc mã nguồn chính (`Web_English`) và thư mục tài liệu báo cáo (`docx`).
